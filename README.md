# Облака — меню

Готовий статичний сайт: головна сторінка та меню українською мовою.
Відкрийте `index.html` через Live Server у VS Code. Встановлювати пакети не потрібно.

## Файли

- `index.html` — головна, контакти, соцмережі та карта.
- `menu.html` — готовий каталог; його створює скрипт нижче.
- `menu-data.js` — розділи, назви, ціни в гривнях, описи й фото страв.
- `script.js` — пошук, навігація, вікна страв, галерея та копіювання.
- `style.css` — оформлення обох сторінок.
- `images/menu/` — оптимізовані локальні фотографії страв.

## Як змінити меню

1. Змініть потрібну позицію у `menu-data.js`.
2. У терміналі папки проєкту виконайте `node tools/build-menu.cjs` (потрібен Node.js).
3. Оновіть сторінку. Скрипт змінює тільки `menu.html`.

Кнопки «Бар», «Коктейльна карта» та «Винна карта» ведуть до відповідних
розділів єдиного довгого меню. Пошук працює за назвами та інгредієнтами.

Дані отримані з публічного меню https://oblaka.choiceqr.com/menu 14.10.2026.
Це збережена копія: ціни й доступність не оновлюються автоматично.
414 позицій, 178 фотографій. Порожні записи джерела пропущені.

Google Fonts та карта потребують інтернету. Для копіювання контактів потрібні
localhost (Live Server) або HTTPS; якщо доступ до буфера заборонено, відкриється
текст для ручного копіювання. «Надіслати відгук» відкриває поштову програму.
Оформлення замовлень і вхід в акаунт не реалізовані; іконка профілю показує контакти.

Для GitHub Pages достатньо опублікувати файли цієї папки. Папку `images`
та `menu-data.js` також потрібно завантажити. Особиста сторінка-сюрприз: love.html. Інструкція з редагування: КАК-РЕДАКТИРОВАТЬ.md.
